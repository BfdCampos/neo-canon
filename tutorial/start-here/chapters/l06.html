You don’t have to remember to run a pass. When you stop typing for a minute and a half, Canon checks the paragraphs you changed in the chapter you’re in. It needs no reader for this: it checks against the facts it keeps.

It never interrupts: no sound, no badge, nothing while you type. If you’re still paused when it finishes, a faint underline appears. Your first keystroke clears the marks in the paragraph you’re writing.

Edit → Check Continuity When I Pause turns it on and off. In a hurry? ⌘' runs a full pass at once.
